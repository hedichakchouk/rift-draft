# Rift Draft
Public squad tier list + Summoner's Rift draft board (drag & drop champions) + "Guess the champ" game.

## Add players
Edit `src/data/players.json` (tiers S/A/B/C/D, per-lane tiers, champion pool using Data Dragon ids like `MissFortune`). Push to `main` and GitHub Pages redeploys.

## Dev
`npm install && npm run dev`  ·  deploy: push to `main` (Settings → Pages → Source: GitHub Actions).
